# Java Calculator App

A simple Java-based calculator application that evaluates mathematical expressions.

## Project Structure

The application consists of two files:

- **`Main.java`**: The entry point of the program.
- **`Calculator.java`**: Contains the core logic for evaluating expressions.

## How to Run

1. **Compile the files:**
   ```sh
   javac Main.java

2. **Run the Program:**
   ```sh
   java Main.java


```java
Calculator calc = new Calculator("3 + 5 * 2");
float result = calc.calculate();
System.out.println("Result: " + result);
